# Altar-1 deployment

[Altar-1](https://huggingface.co/AikidoSec/altar-1) is deployed by Adverserial
AI as **two replicas**, each running on **4× NVIDIA H200 GPUs**, with a
**131,072-token context limit**.

The serving configuration follows the deployment guidance in the model's
[Hugging Face model card](https://huggingface.co/AikidoSec/altar-1).
