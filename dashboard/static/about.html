What is CyberPVP?

CyberPVP is a public, verifiable dual-model cybersecurity arena. Two AI agents attempt the same cybersecurity challenges, under the same conditions, side by side — and every action they take is published as evidence.

The benchmark

Tasks come from CyberGym, a UC Berkeley benchmark of 1,507 real-world vulnerabilities drawn from production open-source projects (OSS-Fuzz / arvo). The agent receives a vulnerable repository, and must produce a proof-of-concept input that crashes the target. A local, non-public judge executes every PoC; a crash means the task is solved.

The match

A match is 100 tasks, sampled deterministically (seed-recorded) across the whole benchmark, plus a fixed 10-task reference subset. Duplicated into two lanes:

  • Left — CyberKimi by Adverserial AI (Kimi, via api.adverserial.ai)
  • Right lane takes the same role for the challenger (Altar-1 when its serving endpoint is live; otherwise a second CyberKimi instance)

Both sides work the identical task list in the identical order with identical budgets (iterations, wall-clock, token ceiling). The match manifest — tasks, models, endpoints, harness SHAs, budgets— is written before the first iteration and published afterwards.

Why you can trust what you see

  • Every event is evidence. Each lane's agent writes a JSONL event stream: prompts, commands run in the sandbox, output, token usage per call, judge verdicts. Both streams are broadcast live here.
  • Checksums. Every published trace file is sha256-listed in checksums.txt, verified on import, then pushed to the public evidence repository: github.com/lordx64/cyberkimi-pvp.
  • Scoring only by the judge. A solve happens only when the CyberGym judge executes a generated PoC and the target crashes (exit_code ≠ 0).

Reading the research view

  • Race to the top — cumulative % of tasks solved vs time, both lanes on one axis.
  • Iterations / tokens — how much work and budget each side needed.
  • Per-task outcomes — seconds, turns, tokens and verdict per task, with per-side totals.

Goal

Show, with reproducible evidence, how security-tuned language models actually perform on real-world vulnerability reproduction — no screenshots, no cherry picking, every trial and dollar in public.
